# Checklist de Deploy

## 1. Preparação

- [ ] Remover console.logs de produção
- [ ] Verificar variáveis de ambiente
- [ ] Testar build local
- [ ] Verificar otimização de imagens
- [ ] Verificar performance com Lighthouse

## 2. Banco de Dados

- [ ] Backup do banco de dados
- [ ] Verificar índices
- [ ] Testar políticas de segurança
- [ ] Configurar rate limiting

## 3. Segurança

- [ ] Headers de segurança configurados
- [ ] CSP implementado
- [ ] Autenticação testada
- [ ] Roles verificados

## 4. Performance

- [ ] Lazy loading implementado
- [ ] Imagens otimizadas
- [ ] Cache configurado
- [ ] Bundle size otimizado

## 5. Deploy

- [ ] Conectar com Vercel/plataforma
- [ ] Configurar domínio
- [ ] Configurar SSL
- [ ] Monitoramento ativo
